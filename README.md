1. Install a userscript manager extension (Tampermonkey or Violentmonkey)
2. Click the userscript manager icon → "Create a new script"
3. Paste contents of [`Google-AI-Studio-Deep-Indigo-Plum.user.js`](./Google-AI-Studio-Deep-Indigo-Plum.user.js) and save
4. Navigate to [Google AI Studio](https://aistudio.google.com/) — the theme auto-applies!

## 🎯 Design Philosophy

> **"Not just beautification — a more focused conversational experience."**
>
> Through deep analysis of Google AI Studio's DOM structure, we remove redundant visual noise, optimize layout contrast, and bring it closer to a professional IDE development environment.

<br />

## ✨ Key Enhancements

<table>
  <tr>
    <td width="50%">
      <h3>🚀 Extreme Layout</h3>
      <p>Redefined golden ratio between sidebar and main stage, increasing content breathing room for long-duration dialogue comfort.</p>
    </td>
    <td width="50%">
      <h3>🧑‍💻 Developer Friendly</h3>
      <p>Pixel-level tuning of Markdown code blocks, enhanced syntax highlighting contrast, monospace font rendering for readability.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>🎨 Focus Mode</h3>
      <p>Amplified input box focus state, subdued inactive components, helping users lock in on the current task faster.</p>
    </td>
    <td width="50%">
      <h3>🕶️ Deep Dark Mode</h3>
      <p>Fixed grayscale anomalies in native mode with deeper, eye-protecting color values that reduce blue light strain.</p>
    </td>
  </tr>
